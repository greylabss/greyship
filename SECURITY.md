# Security

Greyship runs other people's code, so security reports matter a lot.

**Please report vulnerabilities privately**: use this repository's **Security** tab, then **Report a vulnerability**
(GitHub private vulnerability reporting). Don't open a public issue or pull request for it.

Include what you found, how to reproduce it, and what it lets someone do. We'll acknowledge it within a few days, tell
you when it's fixed, and credit you if you like.

Especially interesting: escaping a sandbox, reaching another tenant's app or the host, reading another team's data
or secrets, bypassing authorization, and request forgery against the dashboard or API.

Greyship is early software: until a stable release, only the latest version gets security fixes.
