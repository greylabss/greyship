title: Quickstart
description: Install grey, log in, and deploy a Go backend.
---

From nothing to a live Go backend in four steps. Already have a Greyship to deploy to (the beta instance at
`app.greyship.tech`, or one your team runs)? Skip to step 2.

## 1. Install Greyship on your server

On a fresh Ubuntu or Debian server, as root:

```sh
curl -fsSL https://greyship.tech/install | sudo sh
```

It installs everything one server needs (the API, the dashboard, the builder, the sandboxes and the HTTPS router),
prints the address of your new dashboard, and asks you to create the owner account. No domain is needed to start. Read
[Install Greyship](/self-hosting) first for requirements (ports 80 and 443 must be free), custom domains, backups and upgrades.

## 2. Install the CLI

On your own computer:

```sh
curl -fsSL https://greyship.tech/cli/install | sh
```

macOS and Linux (Intel and ARM). On Windows, run it inside WSL. See [Installation](/installation) for details.

## 3. Log in

```sh
grey login
```

Your browser opens; sign in with the email and password your instance admin gave you, then approve the device. Using another Greyship? Run `grey login <its address>`.

Point `grey` at your Greyship first, once: `grey server https://app.greyship.tech` for the beta, or the address of your own.

## 4. Deploy

In any Go project (a folder with a `go.mod`):

```sh
grey deploy
```

```text
Created project shellhaki/testapi

  testapi  web  .  starts a server in main.go:13 (http.ListenAndServe)

Building here with go1.27.3 for linux/amd64
Uploaded 1 binaries (2.4 MB)

Deployment 5e7c26de-6e97-422e-8ac1-4a70528e3d19 queued:
  │ using the 1 binaries built on your machine
  │ checked testapi: Go 1.27.3, linux/amd64 (5.6 MB)
  │ starting testapi on your-server
  │ live

✓ Live
  testapi  https://testapi-testapi.greyshipapp.tech
```

The first deploy creates the project, named after your module (`github.com/you/shop` → `shop`), and writes
`.greyship/project.json` so later deploys know where to go. It's safe to commit.

## 5. Watch it run

```sh
grey logs -f
```

Open the URL; the first request after a while wakes the service. Then open
your dashboard to see deployments, logs and env vars.
