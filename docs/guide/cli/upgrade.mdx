Downloads the latest grey release, checks its checksum and replaces this program with it. Your login and the server grey uses are kept. Give a version, e.g. grey upgrade v0.1.2, to install that one instead. To update the server itself, run greyship-admin upgrade on it.

```text
grey upgrade [version]
```
