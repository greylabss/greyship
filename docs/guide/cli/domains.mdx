List this project's addresses, including custom domains

```text
grey domains
```

### `grey domains add`

Points a hostname at one of this project's web services. Create the DNS record yourself: a CNAME to the service's default address (or an A record to the server's IP for a name without a subdomain). HTTPS is set up automatically the first time the name is visited, once DNS answers. Say --service when the project has several.

```text
grey domains add <hostname> [flags]
```

Flags:

```text
      --service string   the web service, when the project has several
```

### `grey domains remove`

Stop serving a custom domain

```text
grey domains remove <hostname>
```

Also: `rm`.
