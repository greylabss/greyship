List this project's addresses, including custom domains

```text
grey domains
```

### `grey domains add`

Points a hostname at one of this project's web services. Create the DNS record yourself: a CNAME to the service's default address (or an A record to the server's IP for a name without a subdomain). HTTPS is set up automatically the first time the name is visited, once DNS answers. Say --service when the project has several.

```text
grey domains add <hostname> [flags]
```

Flags:

```text
      --service string   the web service, when the project has several
```

### `grey domains connect`

For a domain on Cloudflare, prints a link that opens Cloudflare and adds the record after you approve it. Not every domain can do this; then add the record from grey domains add by hand.

```text
grey domains connect <hostname>
```

### `grey domains remove`

Stop serving a custom domain

```text
grey domains remove <hostname>
```

Also: `rm`.

### `grey domains verify`

Looks up the domain's DNS record and says whether it points at this Greyship. With --wait it keeps checking until it does (up to 10 minutes), like the dashboard. The first time it points here, HTTPS is prepared for it.

```text
grey domains verify <hostname> [flags]
```

Flags:

```text
      --wait   keep checking until the domain points here
```
