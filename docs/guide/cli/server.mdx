Without an address, shows the server grey uses. With one, e.g. grey server http://203.0.113.7:8000 or grey server https://greyship.example.com, points grey at that server without logging in; grey login then logs in to it. The installer a self-hosted Greyship hands out does this for you.

```text
grey server [address]
```
