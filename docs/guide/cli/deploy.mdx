Builds the Go module in this folder and deploys it. With Go installed, the services are compiled here for Linux and only changed binaries are uploaded. Without Go, or with --remote, the source is packed (honouring .gitignore and .greyshipignore; .env files and .git are never uploaded) and built on Greyship. Without grey init, the project is created from the go.mod name.

```text
grey deploy [flags]
```

Flags:

```text
      --prune    remove stored variables that aren't in .env.prod
      --remote   upload the source and build on Greyship, even with Go installed
      --yes      apply .env.prod changes without asking (for CI)
```
