Deploy from GitHub: every push to the connected branch deploys

```text
grey github
```

### `grey github connect`

Deploy this folder's project on every push to a branch of OWNER/REPO

```text
grey github connect OWNER/REPO [flags]
```

Flags:

```text
      --branch string   branch that deploys (default: the repository's default branch)
```

### `grey github deploy`

Deploy the latest commit of this project's connected GitHub branch

```text
grey github deploy
```

### `grey github import`

Deploy a public GitHub repository from its link; later commits deploy with grey github deploy

```text
grey github import URL [flags]
```

Flags:

```text
      --branch string   branch to deploy (default: the repository's default branch)
```

### `grey github install`

Open the page that installs the Greyship GitHub app for your team

```text
grey github install
```

### `grey github repos`

List the repositories the Greyship GitHub app can read

```text
grey github repos
```
