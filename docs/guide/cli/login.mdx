Logs this machine in. With no argument it uses the Greyship you last logged in to, or greyship.tech. Give the address of a self-hosted Greyship to log in to it instead, e.g. grey login https://greyship.example.com; grey remembers it for every later command.

```text
grey login [server] [flags]
```

Flags:

```text
      --force        log in again even if already logged in
      --no-browser   print the URL instead of opening a browser
```
