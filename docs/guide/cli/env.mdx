Manage the project's environment variables

```text
grey env
```

Flags:

```text
      --env string   production or preview (default "production")
```

### `grey env ls`

List variable names (values stay hidden)

```text
grey env ls
```

Also takes its parent's flags:

```text
      --env string   production or preview (default "production")
```

### `grey env pull`

Download the stored values into .env.prod (the only command that downloads secrets)

```text
grey env pull [flags]
```

Flags:

```text
      --yes   overwrite .env.prod without asking
```

Also takes its parent's flags:

```text
      --env string   production or preview (default "production")
```

### `grey env push`

Load a whole file (default .env.prod), after showing which keys change

```text
grey env push [file] [flags]
```

Flags:

```text
      --prune   also remove stored variables that aren't in the file
      --yes     don't ask before changing variables
```

Also takes its parent's flags:

```text
      --env string   production or preview (default "production")
```

### `grey env rm`

Remove variables

```text
grey env rm KEY...
```

Also takes its parent's flags:

```text
      --env string   production or preview (default "production")
```

### `grey env set`

Set variables; services that use them restart with the new values

```text
grey env set KEY=VALUE...
```

Also takes its parent's flags:

```text
      --env string   production or preview (default "production")
```
