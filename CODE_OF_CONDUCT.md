# Code of conduct

Be kind and be useful. We follow the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/):
harassment, personal attacks and discrimination aren't welcome in issues, pull requests, discussions or anywhere else
the project is represented.

Report a problem privately to the maintainers through GitHub (a private message, or the Security tab for anything
serious). We'll look into it and respond.
